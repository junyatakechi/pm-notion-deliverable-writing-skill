# Notion に書くときの落とし穴

[SKILL.md](../SKILL.md) の「4. 書き替える」で、Notion の本文を書く前に読む。

| 落とし穴 | 起きること | 避け方 |
|---|---|---|
| `.md` や `.com` で終わる語を地の文に置く | Notion が存在しないURLへのリンクにする | `` `AGENTS.md` `` のようにコードスパンに入れる |
| `**太字**` の直後にコードスパンを続ける | 太字の区切りが崩れる | 太字とコードの間に語を挟むか、どちらかに寄せる |
| 表のセルにHTMLタグを書く | `<b>` などが文字のまま表示される | セルの中も Markdown 記法で書く |
| `replace_content` で全体を書き替える | 本文に付いたコメントが位置を失う | 事前にユーザーに伝える。部分的な変更なら `update_content` を使う |
| `update_content` の `old_str` を記憶で書く | 一致せず置き換わらない | `notion-fetch` の出力からそのまま写す。表の `<td>` や、コードブロックの中の空白も含める |
| 非公開ページへのメンションを公開する本文に置く | 閲覧者には開けないリンクが残る | 公開する文書では、メンションを外して文で言い換える |
| `# ` 見出しの下に区切りを置かない | 章の切れ目が見えにくい | `# ` 見出しの直後に `---` を置く。`## ` 以下には置かない |

- コードブロックの言語は、フォルダ構成や設定なら `plain text`、シェルなら `bash`、Markdown の雛形なら `markdown` にする。
- `update_content` で置き換えたあとは、警告が返っていないかを見る。一致しなかった置き換えは、警告に出るだけでエラーにならない。
